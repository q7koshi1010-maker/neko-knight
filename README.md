# ネコの騎士のぼうけん 🐱⚔️

手描きイラストのキャラクターと背景をつかった、横スクロールアクションゲーム（HTML5）。

## あそびかた（かんたん）
`index.html` をブラウザで開くだけ。インターネット接続は不要です。

- ただし一部のブラウザは、ローカルファイルを直接開くと画像を安全のため止めることがあります。
  そのときは下の「ローカルサーバーで開く」を使ってください。

### ローカルサーバーで開く（推奨・確実）
このフォルダーで次を実行し、表示された `http://localhost:8000` をブラウザで開く：

```bash
cd "百花ゲーム01/game"
python3 -m http.server 8000
```

## 操作
| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | ← → / A D | 画面左下の ◀ ▶ |
| ジャンプ | Space / ↑ / W | 右下の ⤴ |
| 攻撃（剣） | J / Z | 右下の ⚔ |
| ガード（盾） | K / ↓ / S | 右下の 🛡 |
| ポーズ | P | — |
| リスタート | R | — |
| 音のON/OFF | M | 右上の 🔊 |

> 音（BGM・効果音）は Web Audio API で合成しており、外部ファイル不要でオフラインでも鳴ります。
> ブラウザの自動再生制限のため、**「スタート」を押した時点**で音が有効になります。設定はブラウザに記憶されます。

## むら（拠点）とキャラ変更 🏘️
- ゲームは**むら**からスタート。家・かじ屋・滝のある平和な村を歩けます。
- 村の右に**2つの看板（ぼうけん1へ／ぼうけん2へ）**。看板の前で **↑** を押すとそのステージへ。冒険の左端の看板（← むら）で村へ戻れます。
- **ステージ2はステージ1をクリアすると解放**されます（それまでは 🔒）。**ステージ2は敵が多く・速く・強く、ボスのHPも増加**（8 → 15）。
- **かじ屋**の前で **↑（ジャンプ）**を押すとショップが開き、**あつめた星をつかって新しいなかまを解放・切り替え**できます（通り抜けるだけでは開かないので先へ進めます）。
  - **なかま**：ネコの騎士（最初から）／イヌの騎士（★15）／アザラシの魔法使い（★25）／**ペンギン（★150）**／**パンダ（★115）**
  - **ぶき**（誰でも装備でき、武器だけでも買える）：けん（最初から）／**じゅう（★80・とおくの敵を弾でうてる）**／**おの（★50・つよい／リーチ広め・ダメージ2）**／**金ぞくバット（★50・ふきとばす）**
  - 星と解放したキャラはブラウザに**保存**され、次に開いても引き継がれます。
- 死神ボスを倒してゴールすると、**むらに帰ってクリア**。

## ルール
- 星をあつめると貯金される（かじ屋でキャラと交換できる通貨）。
- 敵は「剣で攻撃」か「上から踏む」と倒せる。
- **ガード（盾）**：ボタンを押している間、**向いている方向**からの敵や弾を盾で防ぐ（その間は移動・ジャンプ・攻撃はできない。左右キーで盾の向きを変えられる）。上から落ちる雷は防げない。
- 敵にぶつかる／穴に落ちるとハートが1つ減る。ハート0でゲームオーバー。
- 最後の死神ボスを倒すとゴールが出現。ゴールの看板に触れてクリア！

## キャラクター（元の手描きイラストより）
プレイヤー＝ネコの騎士。敵＝サメ・コウモリ・おばけ・炎の悪魔・魔法使い・雨雲、
ボス＝死神。アイテムの星はアザラシの「星の杖」がモチーフ。

## ファイル構成
- `index.html` … 画面とUI
- `game.js` … ゲーム本体（物理・敵AI・カメラ・描画）
- `audio.js` … 効果音・BGM（Web Audio APIで合成、外部音源ファイル不要）
- むら＝`village_*`、キャラ＝`cat/dog/seal_*` のSVG。星・解放・選択キャラは localStorage に保存
- `assets.js` … 各SVGを埋め込んだデータ（`build_assets.js` で生成）
- `assets/*.svg` … キャラ・背景の元データ（手描きの絵柄をベクター化）
- `build_assets.js` … `assets/*.svg` → `assets.js` を作り直すスクリプト（`node build_assets.js`）

## 絵を差し替えたいとき
`assets/` のSVGを編集 → `node build_assets.js` を実行 → ブラウザを再読み込み。
